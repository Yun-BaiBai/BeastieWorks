**安装**：下载下面的 `Beastie-Works-1.0.3-win-x64-setup.exe`，双击安装，可以直接装在 1.0.x 上面。安装包还没有数字签名，Windows 提示"已保护你的电脑"时，点"更多信息" → "仍要运行"。

**1.0.0–1.0.2 的安装包有严重问题，请升级**：打包时漏掉了两样东西，装 agent 会失败（"failed (7)"），跟 agent 说话会报 `Cannot find package 'zod'`。从开发环境跑的测试全过，所以没发现。1.0.3 修好了，并且以后每次打包都会在打好的程序上直接检查一遍：能不能装 agent、能不能跟 agent 说话、数据库和语音能不能用；有一项不行就不出安装包。

**这一版改的**
- 修好装 agent 和跟 agent 说话（见上）。
- 装 Antigravity 这类整包下载的 agent，网速慢时不会再下到 10 分钟就被掐断（"TimeoutError"）：边下边存，只有两分钟一点都没下来才算失败。
- 第一次打开时自动给三个角色挑 agent，优先挑已登录、真派过活的（Codex、Claude、Antigravity、DeepSeek Harness），审查挑另一家；不会再挑到 Gemini 这类个人账号已经用不了的。
- 装 agent 时显示下载进度："已下载约 79 MB，用了 60 秒"，不会再只显示"正在接上…"看着像卡住。下载大小的说明也改准了：主包之外，连带的包可能大很多（比如 Claude、Gemini 一两百 MB）。

Beastie Works 1.0.3. **Please upgrade from 1.0.0–1.0.2**: those installers left out two things when packaging, so installing an agent failed ("failed (7)") and talking to one failed with `Cannot find package 'zod'`. Fixed, and every build now checks the packaged program itself (installing an agent, the agent protocol library, the database, speech) and stops if anything fails. Installing an agent now shows how much has downloaded; a slow whole-archive download (Antigravity) is no longer cut off after 10 minutes; first-run role picks prefer signed-in agents that have done real work. The installer is not code-signed yet ("More info" → "Run anyway").
