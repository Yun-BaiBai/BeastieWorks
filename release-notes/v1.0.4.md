**安装**：下载下面的 `Beastie-Works-1.0.4-win-x64-setup.exe`，双击安装，可以直接装在 1.0.x 上面。安装包还没有数字签名，Windows 提示"已保护你的电脑"时，点"更多信息" → "仍要运行"。

**这一版改的**
- **装 agent 中途被打断，不会再留下装了一半的东西**：以前装到一半关掉程序（或者断电、崩溃），留下的半截会被当成"已装好"，一用就报错（比如选 Claude 时"没读到它的模型：Internal error"）。现在先装进旁边的临时文件夹，装完整了才挪过去；没装完的会清掉，下次重新装。
- **第一次打开的页面上，选了还没登录的 agent，会直接在这里出"去登录"**，不再显示看不懂的错误。登录好后自动再问它有哪些模型。
- **小怪要用你自己的连接器（比如 Notion）时，会弹框问你**："允许这次" / "这张工单都允许" / "不允许"，在哪个页面都看得到。以前审批规则一律拒绝，你在对讲栏说"放行"也没用，"再试一次"也一样卡住。工具名看着会改东西（新建、修改、删除……）的，框里会写明。10 分钟不点算不允许。
- **交付页重新排过**：先一句话说它做了什么，其余点"展开全文"；改了的文件一行一个，写着加了几行、删了几行，点开才看具体改动；它怎么验证的、你的原话、审查意见都先只露几行。"收下"和"打回"一直在底部，不会被挤出去。工位页也一样：上面是工单标题，你的原话先露两行，不再用大字铺满整页、盖住插话框。中文文件名不再变成一串乱码，重启后用时和花费也照样显示。

如果你在 1.0.3 里装 agent 时中途关过程序，那个 agent 可能是半截的：在"agent 名单"里点开它，卸载后再装一次。

Beastie Works 1.0.4. An agent install cut off half way (closing the app, a crash) no longer leaves a half-installed agent that counts as installed: packages go into a folder beside it and are moved into place only when complete. On the first-run page, an agent that is not signed in now offers "Sign in" right there instead of an error. The delivery page leads with one line on what was done, and the desk page no longer fills the screen with the original words; the delivery page lists changed files one per line (open one to see its change), and folds the rest; Chinese file names are no longer garbled, and time and cost still show after a restart. When a gremlin wants one of your own connectors (Notion…), you are asked: allow once, allow for this ticket, or not (before, the approval rule refused it even after you said yes). If you closed the app while an agent was installing in 1.0.3, remove that agent in the agent list and install it again. The installer is not code-signed yet ("More info" → "Run anyway").
