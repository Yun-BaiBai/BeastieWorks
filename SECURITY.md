# 安全问题 Security

发现安全问题请不要开公开的 Issue。请在 GitHub 上用这个仓库的 "Report a vulnerability"（Security → Advisories）私下报告，说明怎么重现、影响到什么。

Please do not open a public issue for a security problem. Report it privately through this repository's "Report a vulnerability" (Security → Advisories), with how to reproduce it and what it affects.
